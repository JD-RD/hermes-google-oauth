Privacy policy

Last updated: 7 November 2026

Who this applies to

This OAuth client is used by a single person, for that person's own Google account only. It has no other users and is not offered as a service.

What is accessed

With the owner's explicit consent, the application may access, through Google APIs:

  • Google Calendar: event titles, times, locations, attendees and descriptions, in order to read and create or modify calendar events;
  • Google Drive: file names, metadata and contents, in order to search, upload, download and organise the owner's own files;
  • Google Docs: document contents, in order to read and edit documents.

No Gmail, Contacts or other Google data is requested.

Where the data goes

Data is retrieved directly from Google's APIs to the owner's own computer. It is not sent to any third party, not sold, not used for advertising or profiling, and not used to train models.

The OAuth refresh token is stored locally on that computer (~/.hermes/google_token.json, file mode 0600) and is only used to authenticate API calls to Google. Calendars, files and documents may be cached locally by the agent for the duration of a task.

Retention and deletion

Nothing is retained on any server: there is no server. Locally cached copies can be deleted at any time by the owner. Access can be revoked at any moment at myaccount.google.com/permissions, which invalidates the stored token immediately.

Cookies and analytics

These pages set no cookies, load no external scripts, fonts or trackers, and perform no analytics. The application itself has no web interface.

Contact

Questions about this policy: open an issue at github.com/JD-RD/hermes-google-oauth/issues.
